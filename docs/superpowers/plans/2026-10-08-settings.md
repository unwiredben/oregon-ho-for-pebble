# Settings Implementation Plan

> Execute inline using executing-plans; the approved design authorizes implementation.

**Goal:** Deliver Oregon Ho! 1.3.0 with custom party names and No guns settings.

**Architecture:** The Trail model owns validated names and event policy. A settings
module bridges AppMessage and persistence. Clay provides the offline phone page.
Scene rendering measures the full story at progressively smaller fonts in one panel,
shortening only the name if Gothic 14 still cannot fit it.

**Tech stack:** Pebble SDK 4.33.1, native C, PebbleKit JS, @rebble/clay, host C/Node tests.

## Constraints

Keep the UUID, watchface type and all four targets. Use at most five custom names,
96 UTF-8 bytes each; ignore blank names and use defaults when all are blank.
No guns defaults off. Preserve animation state on settings updates. Persist each
name separately. Warn live about likely overflow; fit actual text on the watch.

- [x] Extend `tests/trail_test.c` with custom-only, sparse-slot, blank fallback,

## Task 3: Rendering and delivery

- [x] Add formatter tests that ensure truncation retains full event suffixes
      and never splits UTF-8 characters; observe failure before implementation.
- [x] Add `src/c/event_layout.c` and regression tests for full-message font selection.
      Update `src/c/scene.c` to measure names and messages, trying smaller fonts
      before shortening names. Fit one panel within the ground area and round
      screen boundary; cache text in static buffers to avoid exhausting the watch stack.
- [x] Run `validate_project.py`, `pebble build`, host checks and sanitizer checks.
- [x] Add `tools/verify_settings.py` using isolated emulators and real AppMessage
      packets; exercise ordinary/long/wide names, No guns, restart and clearing.
      Save screenshots and a validation report under `previews/settings/`.
- [x] Inspect screenshots, update README settings and verification details, review
      final diff and deliver `oregon-ho-1.3.0.pbw` with actual verification limits.

## Verification result

The four-target SDK build and strict host C tests passed, including address and
undefined-behavior sanitizer checks. Clay bundle and actual HTML DOM checks
passed. Isolated Basalt, Chalk, Emery and Gabbro emulators accepted settings,
rendered ordinary, long, wide and Unicode names in one panel, preserved settings
through restart, and restored defaults when cleared. Captures and panel geometry
checks are in `previews/settings/`. Physical hardware was not tested.
